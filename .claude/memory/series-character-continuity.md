When an episode continues a series and the previous episode's last image already shows the main figure at the new age/place, use that image as the character reference instead of designing a new one. User 2026-11-25, episode 1941: "ở tập trước ảnh cuối có hình bác (Cao Bằng 1941). nên dùng hình đó làm nhân vật nhé" (= history/projects/1931-vu-an-tong-van-so/images/_goc-chua-chu/s097.jpg).

**Why:** continuity across episodes; the user already approved that look. This is an exception to "each episode stands alone" (which still applies to scene images and minor characters, e.g. the new mật thám).
**How to apply:** before designing characters for a new series episode, check the previous episode's closing images for the recurring figure and propose reusing it. See [[history-video-style-prefs]], [[draw-revered-figures-face]].
